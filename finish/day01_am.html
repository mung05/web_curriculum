1 CSS 변수 — 색상 한 번에 바꾸기

BREWVENTI 사이트는 :root에 색상 변수를 선언해서 사용합니다.
버튼을 클릭하면 JS가 :root의 --color-primary 값을 바꿉니다.
CSS 변수 하나를 바꾸면 연결된 모든 색상이 한 번에 바뀌는 것을 확인하세요.

BREWVENTI 헤더 색상
// CSS 변수를 JS에서 바꾸는 방법
document.documentElement.style.setProperty('--color-primary', '#새색상');

// BREWVENTI :root 선언 위치
:root {
  --color-primary: #3D1F8F;
  --color-accent: #FF6B2B;
}

2 DOM 선택 — 메뉴 이름 바꾸기

querySelector로 요소를 선택하고 textContent로 내용을 바꿉니다.
BREWVENTI 메뉴 카드에서 이름을 표시할 때 사용하는 방식입니다.

버튼을 클릭하세요
// DOM 선택 + textContent 변경
const display = document.querySelector('#menu-display');
display.textContent = `${name} — ${price}`;

// 선택이 잘 됐는지 확인하는 방법
console.log(display); // null이면 선택 실패!

3 classList — 로고 스타일 토글

BREWVENTI 헤더는 스크롤하면 classList로 'scrolled' 클래스를 추가합니다.
add / remove / toggle / contains 4가지 메서드를 직접 눌러서 확인하세요.

BREWVENTI
const el = document.querySelector('#logo-box');

el.classList.add('active'); // 클래스 추가
el.classList.remove('active'); // 클래스 제거
el.classList.toggle('active'); // 있으면 제거, 없으면 추가
el.classList.contains('active'); // true / false 반환

4 scroll 이벤트 — 스크롤 위치 감지

BREWVENTI 헤더는 스크롤 50px 이상이면 배경이 바뀝니다.
아래 숫자는 현재 페이지의 scrollY 값을 실시간으로 보여줍니다.
페이지를 스크롤하면서 값이 바뀌는 것을 확인하세요.

scrollY: 0px

↕ 페이지를 스크롤해보세요

// BREWVENTI 헤더 스크롤 감지 코드
window.addEventListener('scroll', () => {
  const y = window.scrollY; // 현재 스크롤 위치(px)

  if (y > 50) {
    header.classList.add('scrolled');
  } else {
    header.classList.remove('scrolled');
  }
});
