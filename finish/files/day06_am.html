1 이벤트 버블링 — 어디를 클릭했는지 확인

버튼, 내부 박스, 외부 박스 각각에 이벤트가 등록되어 있습니다.
버튼을 클릭하면 이벤트가 위로 전파되는(버블링) 것을 로그로 확인하세요.

외부 박스 (outer) — 클릭 이벤트 있음
내부 박스 (inner) — 클릭 이벤트 있음
// 버블링: 버튼 클릭 → inner → outer 순으로 전파
// e.target: 실제 클릭된 요소
// e.currentTarget: 이벤트가 등록된 요소

outer.addEventListener('click', (e) => {
  console.log('outer 실행!', e.target); // 버튼 클릭해도 여기 실행됨!
});

2 stopPropagation — 버블링 차단

BREWVENTI 모달에서 내부 박스를 클릭해도 닫히지 않는 이유입니다.
내부 박스에 stopPropagation이 적용되어 있어서 외부로 전파되지 않습니다.

외부 클릭 → 닫힘 (배경 역할)
내부 클릭 → 닫히지 않음

stopPropagation() 적용됨

// 모달 박스(내부) 클릭 시 배경으로 전파 차단
modalBox.addEventListener('click', (e) => {
  e.stopPropagation(); // 버블링 차단!
});

// 차단 없으면: 박스 클릭 → 배경까지 전파 → 모달 닫힘
// 차단 있으면: 박스 클릭 → 여기서 멈춤 → 모달 유지

3 드롭다운 — CSS opacity + visibility 패턴

BREWVENTI 내비게이션 드롭다운입니다.
display:none 대신 opacity + visibility를 쓰는 이유: transition 적용 가능!

커피 스무디 티에이드
/* 숨김: opacity 0 + visibility hidden (공간 유지, transition 가능) */
.dd-menu { opacity: 0; visibility: hidden; transition: 0.25s; }

/* 호버 시 표시 */
.dropdown:hover .dd-menu { opacity: 1; visibility: visible; }

/* display:none은 transition 불가! */
/* opacity + visibility 조합이 실무 표준 */

4 모달 — 버블링 차단 적용 완성

BREWVENTI 모달의 완성 패턴입니다.
배경 클릭 → 닫힘 / 내부 클릭 → 유지 를 직접 확인하세요.

// 패턴 정리
openBtn → modalBg.classList.add('active') // 열기
closeBtn → modalBg.classList.remove('active') // 닫기
modalBg → classList.remove('active') // 배경 클릭 닫기
modalBox → e.stopPropagation() // 내부 클릭 차단
