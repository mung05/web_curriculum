DAY 03 — 오전 실습

객체 배열 · filter() · 동적 HTML 렌더링 — BREWVENTI 메뉴 탭 필터의 기반

1 객체 배열 — 메뉴 속성 읽기

BREWVENTI 메뉴 데이터는 객체 배열로 관리됩니다.
버튼을 클릭하면 해당 메뉴의 모든 속성을 읽어서 표시합니다.

const menuData = [
  { name: '아메리카노', category: 'coffee', price: '3,500원' },
  ...
];

// 접근 방법
menuData[0].name // → '아메리카노'
menuData[0].category // → 'coffee'
menuData[0].price // → '3,500원'

2 Array.filter() — 카테고리 필터링

filter()는 조건을 통과한 요소만 담긴 새 배열을 반환합니다.
버튼을 클릭하면 해당 카테고리 메뉴만 걸러냅니다.

// 원본 배열은 변하지 않음 (비파괴적)
const filtered = menuData.filter(item => {
  return item.category === 'coffee';
});

// 화살표 함수 단축형
const filtered = menuData.filter(item => item.category === 'coffee');

3 동적 HTML 렌더링 — 카드 그리드 생성

반복문으로 HTML 문자열을 만들고 innerHTML에 한 번에 삽입합니다.
버튼을 클릭하면 해당 개수만큼 카드가 렌더링됩니다.

let html = ''; // 빈 문자열에 누적

for (const item of filtered) {
  html += `<div class="card">${item.name}</div>`;
}

grid.innerHTML = html; // 한 번에 삽입 (성능 중요!)

4 완성 패턴 — 탭 + filter + innerHTML 조합

BREWVENTI 메뉴 섹션의 핵심 패턴입니다.
위 세 가지가 합쳐진 완성 버전을 확인하세요.

// 세 가지 조합 흐름
function renderMenu(category) {
  // 1. filter로 데이터 추출
  const filtered = category === 'all'
    ? menuData
    : menuData.filter(item => item.category === category);
  // 2. HTML 생성
  let html = '';
  for (const item of filtered) { html += `...`; }
  // 3. 렌더링
  grid.innerHTML = html;
}
