1 IntersectionObserver — 스크롤 페이드인

아래로 스크롤하면 박스가 화면에 들어올 때 나타납니다.
BREWVENTI About 섹션에서 사용하는 패턴과 동일합니다.

BREWVENTI — 두 번째 박스
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) { // 화면에 보이면
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.3 }); // 30% 보일 때 실행

document.querySelectorAll('.fade-box').forEach(el => observer.observe(el));

2 threshold 0.2 vs 0.8 비교

왼쪽은 20% 보이면 실행, 오른쪽은 80% 보여야 실행됩니다.
스크롤하면서 어느 시점에 활성화되는지 비교하세요.

↓ 스크롤하면서 비교하세요
threshold: 0.2
(20% 보이면 실행)
threshold: 0.8
(80% 보여야 실행)
// threshold 값 비교
{ threshold: 0 } → 1픽셀이라도 보이면 즉시
{ threshold: 0.2 } → 20% 이상 보이면
{ threshold: 0.5 } → 절반 이상 보이면
{ threshold: 1 } → 전체가 다 보여야
