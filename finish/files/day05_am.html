1 정규식 — 실시간 패턴 검사

BREWVENTI 예약 폼에서 전화번호를 검사할 때 정규식을 사용합니다.
010-0000-0000 형식으로 입력해보세요.

형식이 맞지 않습니다
const regex = /^010-\d{4}-\d{4}$/;

// 패턴 분해
^      → 문자열 시작
010-  → "010-" 그대로
\d    → 숫자 한 자리 (0~9)
{4}   → 앞 패턴 4번 반복
$      → 문자열 끝

regex.test('010-1234-5678') → true
regex.test('01012345678') → false

3 disabled — 버튼 활성화 조건 제어

BREWVENTI 예약 버튼은 이름과 전화번호가 모두 유효할 때만 활성화됩니다.
disabled 버튼과 활성화 버튼의 차이를 확인하세요.

disabled = true (비활성)

disabled = false (활성)

// 비활성화
button.disabled = true;

// 활성화
button.disabled = false;

// 조건으로 한 번에
button.disabled = !(nameOk && phoneOk);
